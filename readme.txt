Automatically generate complete WordPress blog posts, including a featured image, from a single topic using Claude AI and OpenAI.

== Description ==

Trushiv AI Post Generator is a WordPress plugin that automatically generates complete blog posts using **Claude AI** (for content) and **OpenAI** (for the featured image), then publishes them to your site — all from a single topic input.

**Features**

* One-click post generation from just a topic
* Content written by Claude (title, HTML body, excerpt)
* Featured image generated by OpenAI's image model
* Image automatically uploaded to the WordPress Media Library and set as the post thumbnail
* Multi-language support (English, Gujarati, Hindi, Marathi, Tamil, Bengali)
* Choose draft or publish status, and a default category
* Live progress UI while the post is being created

= Third-party services =

This plugin relies on two external, paid API services to generate content:

* **Anthropic (Claude API)** — the post topic you enter is sent to Anthropic's API to generate the title, body, and excerpt. See the [Anthropic Privacy Policy](https://www.anthropic.com/legal/privacy) and [Terms of Service](https://www.anthropic.com/legal/consumer-terms).
* **OpenAI (Images API)** — an image prompt derived from the generated content is sent to OpenAI's API to generate a featured image. See the [OpenAI Privacy Policy](https://openai.com/policies/privacy-policy) and [Terms of Use](https://openai.com/policies/terms-of-use).

You must supply your own API keys for both services, and standard usage-based charges from those providers apply. No data is sent to either service until you click "Generate & Publish Post".

== Installation ==

1. Upload the `trushiv-ai-post-generator` folder to the `/wp-content/plugins/` directory, or install the plugin directly through the WordPress **Plugins** screen.
2. Activate the plugin through the **Plugins** screen in WordPress.
3. Go to **Trushiv AI Post Generator → Settings** and enter your Anthropic and OpenAI API keys.
4. Choose your default post status, language, and category, then click **Save Settings**.

= Getting API keys =

* Anthropic API key: https://console.anthropic.com/settings/keys
* OpenAI API key: https://platform.openai.com/api-keys

== Frequently Asked Questions ==

= Do I need my own API keys? =

Yes. Trushiv AI Post Generator does not include any API access of its own. You must create accounts with Anthropic and OpenAI and add billing to those accounts, then paste your API keys into the plugin's Settings screen.

= Where are my API keys stored? =

API keys are stored in the WordPress options table on your own site. Only users with the `manage_options` capability (typically Administrators) can view or change the plugin's settings pages.

= Does this plugin work alongside WordPress 7.0's AI Connectors? =

Trushiv AI Post Generator uses its own Anthropic and OpenAI API keys (entered on the Settings screen) and does not go through WordPress 7.0's core AI Client or Connectors system, so it is unaffected by that feature either way.

If you separately have the official **AI** plugin from WordPress.org installed and its **Connector Approvals** experiment enabled, that setting only controls plugins that request access through WordPress's shared AI connectors — it does not apply to Trushiv AI Post Generator, since Trushiv AI Post Generator talks to Anthropic and OpenAI directly with the keys you provide.

= What languages can posts be generated in? =

English, Gujarati, Hindi, Marathi, Tamil, and Bengali are available from the Settings screen.
